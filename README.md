# 🛠️ Requirements

To run the Java programs, install the **Java Development Kit (JDK)**.

Check the installation:

```bash
java --version
```

Check the Java compiler:

```bash
javac --version
```

---

# ▶️ Running a Java Program

Navigate to the folder containing the Java file.

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```

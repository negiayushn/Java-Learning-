# Java Loops

Loops are one of the fundamental concepts in programming. They are used to repeatedly execute a block of code without writing the same statements multiple times.

In Java, loops help reduce code repetition and make programs easier to write and maintain.

This file demonstrates the basic loop concepts in Java, including:

- `for` loop
- Nested `for` loops
- Pattern printing
- `break` statement
- `continue` statement
- `while` loop
- `do-while` loop
- Loop initialization
- Loop conditions
- Increment and decrement
- Infinite loops and loop control

# 1. What Are Loops?

Loops are used to repeat a sequence of statements multiple times.

For example, instead of writing:

```java
System.out.println(1);
System.out.println(2);
System.out.println(3);
System.out.println(4);
System.out.println(5);
